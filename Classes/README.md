# В этой папке собраны реализованные мной классы на C++

## Список классов:

### 1. Complex.cpp (Комплексные числа)
Класс для работы с комплексными числами.\
**Реализовано:** 
* конструкторы;
* вывод в консоль;
* сложение и умножение.

### 2. Point.cpp (Точка)
Класс для работы с точкой на координатной плоскости.\
**Реализовано:** 
* вычисление расстояния до начала координат и до другой точки;
* перемещение точки и определение координатной четверти;
* перегрузка операторов: + , -, *, &, ++, <<, >>.

### 3. Rectangle.cpp (Прямоугольник)
Класс для работы с прямоугольником.\
**Реализовано:**
* вывод информации о прямоугольнике;
* перегрузка оператора + и *.

### 4. Triangle.cpp (Треугольник)
Класс для работы с треугольником.\
**Реализовано:**
* вычисление периметра и площади;
* проверка существования треугольника;
* определение типа треугольника;
* перегрузка операторов: +, *, &, ~, --, <, <<, >>.
